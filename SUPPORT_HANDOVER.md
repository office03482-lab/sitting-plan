# Support Handover

## Handover Package Contents

This package must be delivered to the school implementation owner and retained by the platform support owner.

## 1. Admin Credential Sheet

Deliver securely. Never send passwords over open chat.

Template:

- School Name:
- School Code:
- Production URL:
- School Admin Full Name:
- School Admin Email:
- Username:
- Temporary Password:
- First Login Required: `YES`
- Password Change Required: `YES`
- Support Contact Name:
- Support Contact Email:
- Support Contact Phone:

Delivery acceptance:
- School Admin confirms receipt
- Password is changed on first login

## 2. School Onboarding Document

Include:
- Login URL
- First login steps
- Password change instructions
- Branding setup path
- Academic setup path
- User import path
- Subscription and billing visibility path
- Backup request path
- Support escalation path

Acceptance:
- School Admin can complete onboarding without developer intervention

## 3. Teacher Quick Guide

Include:
- Login instructions
- Attendance workflow
- Timetable view
- LMS / assignment workflow
- Online test creation or use flow
- Teacher AI usage
- Password reset request path

Acceptance:
- Teacher can perform daily teaching tasks independently

## 4. Parent Quick Guide

Include:
- Login instructions
- Child dashboard overview
- Attendance view
- Academic progress view
- Test result view
- Alerts view
- Parent AI usage if enabled
- Support contact for access issues

Acceptance:
- Parent can log in and read student information independently

## 5. Student Quick Guide

Include:
- Login instructions
- Dashboard overview
- LMS access
- Online tests
- Study planner
- AI Tutor usage if enabled
- Support path for login issues

Acceptance:
- Student can access daily learning flows without support escalation

Expected issues to prepare for:
- Password reset request
- Missing school branding asset
- Teacher permission question

- Student login confusion
- AI credit depletion question

For each issue document:
- first response owner
- target resolution time
- escalation path
